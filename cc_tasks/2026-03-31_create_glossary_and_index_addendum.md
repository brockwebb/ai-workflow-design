## Correction: "ABBA design" is not a standalone glossary term

The parent task lists "ABBA design" as a new term. This is wrong. The established term from experimental design methodology is **counterbalancing** (or **counterbalanced design**). "ABBA" is just the notation for the simplest counterbalancing pattern (A-B-B-A order).

Chapter 5 already gets this right: it says "This is standard counterbalancing from experimental design, applied to LLM evaluation."

**In the glossary:**
- Entry should be under **counterbalancing** with the definition referencing its application to position bias control in LLM evaluation
- "ABBA" can appear parenthetically within the definition as the notation, not as the entry heading
- Do NOT create a separate "ABBA design" glossary entry

**In the index:**
- Keyword should be "counterbalancing" mapped to Chapter 5
- Do NOT index "ABBA design" as a standalone keyword

**General principle for the entire glossary/index task:** Do not mint glossary entries for common terms that already have established names in experimental design, software engineering, or statistics. Use the established name. If the book uses a shorthand, the glossary entry goes under the proper term with the shorthand noted parenthetically. When in doubt, search for the established term before creating an entry.
